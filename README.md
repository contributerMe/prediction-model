# Freight Rate Prediction

ML assessment for Spotter. Predicts freight rates (USD) for truck loads across the US.

## How to Run

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train the model  (outputs model.pkl)
python src/train.py

# 3. Generate validation predictions
python src/predict.py --input data/validation.csv --output validation_predictions.csv

# 4. Generate December chart predictions
python src/predict.py --input data/december-chart-inputs.csv --output data/december-chart-inputs.csv --december

# 5. Run the scorer (validates files + creates scorer_results/candidate_december.png)
python scores.py --predictions validation_predictions.csv --december-predictions data/december-chart-inputs.csv
```

## Data

| Column | Description |
|--------|-------------|
| pickup / delivery | City names |
| distance | Miles between cities |
| equipment | Dry Van / Reefer / Flatbed |
| weight | Load weight (lbs) |
| date | Load date |
| market_index | External market signal |
| quote_signal | Market quote indicator |
| posted_rate | **Target** — freight rate ($) |

## Model

LightGBM regressor with time-based train/holdout split (train: Jan–Sep 2025, holdout: Oct 2025).

Key features: distance, equipment type, temporal features, market signals, route mean rate.
